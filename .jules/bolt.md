## 2024-05-24 - [IntersectionObserver for Map Lazy Loading]
**Learning:** While dynamic imports (`React.lazy`) with `Suspense` are great for route-level code splitting, they still download and execute the chunk immediately when mounted. If the lazy component is rendered below the fold (like a heavy Leaflet map component on a landing page), it negatively impacts initial load performance by competing for network and main-thread resources with above-the-fold content.
**Action:** Use an `IntersectionObserver` hook (`useIntersectionObserver.ts`) to wrap the `Suspense` boundary of heavy components. Only render the `Suspense` (and thus trigger the network request) when the placeholder skeleton is about to intersect the viewport (e.g., `rootMargin: '200px'`). This provides true lazy-loading.
