## 2026-04-04 - Memoization of Date-Based Filtering\n**Learning:** Date-based array filtering and sorting on large event collections (e.g., separating 'upcoming' from 'past' events using `new Date()`) causes measurable main-thread blocking when executed synchronously in the render path of heavy components like dashboards or tab views.\n**Action:** Always wrap collection processing logic in `useMemo` hooks when the derived state is passed down to lists, ensuring that UI interactions like tab switching or accordion expanding do not trigger a full recalculation.
