## 2024-03-14 - Unsanitized User URLs in `href` Attributes (XSS)
**Vulnerability:** Several components (`UserSocials`, `CollaboratorCard`, `JoinTeamCTA`, `ConnectButton`, `OrgHeader`, `AboutUs`) were injecting user-provided URLs directly into `href` attributes. This could allow an attacker to use `javascript:` schemes to execute malicious code (XSS).
**Learning:** URL sanitization needs to be globally accessible, not just contained within a single component (`UserSocials` had it, but wasn't sharing it). A common utility approach is needed to sanitize all dynamically generated user URLs across the React components.
**Prevention:** Always wrap any user-supplied link passed to `href` in a sanitize function. The `sanitizeUrl` utility from `src/utils/sanitizeUrl.ts` enforces `http/https` protocols and strips out dangerous protocols like `javascript:`, `vbscript:`, and `data:`.
